# OpenVClient 1.0.0-beta.5

The fifth beta of **OpenVClient**, a free, open-source desktop app for databases, object storage and servers, for macOS, Windows and Linux. Website: [openvclient.xyz](https://openvclient.xyz).

> **This is a beta.** Please [report bugs](https://github.com/openvclient/openvclient/issues). Back up anything important before running destructive actions against production systems.

## What's new since beta 4

### New tools
- **ER diagram**: right-click a schema (or a MySQL database) → **ER diagram**. Tables, columns, primary and foreign keys with arrows; drag boxes, zoom, highlight by name, double-click to open the data. PostgreSQL, MySQL/MariaDB, SQLite and SQL Server.
- **Compare schemas**: right-click a schema → **Compare with…**. Two schemas on the same or different connections: tables on one side only, column type and primary-key differences, and a copyable report.
- **Charts**: a **Table / Chart** switch on query results with numbers; bars or a line.
- **SQL formatter** (⌘⇧F), **snippets** (save, insert, also in ⌘K) and **manual commit** mode with Commit and Rollback buttons.
- **Pick up where you left off**: open SQL, table, monitor and Redis tabs are offered again on Home after a restart.

### Grid and editor
- **Freeze columns**: right-click a column header. Wide results now scroll sideways (columns past the edge used to be cut off).
- Right-click a cell to **filter by** or **exclude** its value; recent WHERE filters are one click away.
- Line numbers, cursor line and column in the status bar, a WHERE hint in each database's own SQL, shorter timestamps and your own NULL label (Settings).

### Files
- **Image and PDF previews** in the file manager (PDF page 1 needs `sips` on macOS, built in, or Poppler's `pdftoppm` on Windows and Linux).
- **Per-file progress** for uploads, downloads and deletes; folders show how many items they hold; a resizable preview pane; right-click on empty space for New folder, Upload and Refresh.

### Getting around
- Tabs: right-click for **close others / to the right / all** and **reopen closed tab** (⌘⇧T); ⌘1–9 to switch; an all-tabs list when they overflow.
- **⌘B** hides the sidebar; **⌘K** search ranks better and highlights matches.
- Home: recent queries, **Recent first / By folder**, and the connector list folds away once you have connections.
- Connection dialog: **paste a connection URL** (`postgres://user@host/db`) to fill the form, connectors grouped by kind, errors next to the field.
- Settings: **interface size** (⌘= / ⌘−), query timeout, confirmation on Staging, **export and import connections** (passwords stay in the keychain).

### SSH
Tested against a new lab of real OpenSSH servers (45 checks: every login method, 12 key types and formats, certificates, agent, jump hosts, tunnels, SFTP).
- Older servers (routers, NAS boxes, CentOS 7-era) that only offer hmac-sha1, group14-sha1 or CBC now connect; these are used only when nothing newer is offered.
- Servers that want **a key and a password** now log in.
- Clear messages for a wrong or missing key passphrase.
- Symlinked folders open as folders; deleting a folder deletes what is inside; large transfers stream instead of filling memory.

### Fixed
- Toast notifications no longer pile up over the results; long names end in "…" instead of being cut mid-letter.
- The file list's Size column lines up, SQL tab titles no longer repeat the database, and the plan diagram fits its pane.

## What's inside

### Connectors
- **SQL:** PostgreSQL, MySQL, MariaDB, SQL Server / Azure SQL, SQLite, ClickHouse, GaussDB/openGauss (tested against openGauss), plus a Kingbase preset (PostgreSQL protocol; not yet tested against KingbaseES).
- **SQL Server sign-in:** SQL login, Windows/NTLM and integrated (Windows build), and Microsoft Entra ID: password, service principal, managed identity, device code, default credential chain, access token. Named instances via SQL Server Browser.
- **NoSQL and services:** MongoDB, Redis, Elasticsearch/OpenSearch, RabbitMQ (management API), Docker.
- **Servers and files:** SSH with an interactive terminal, SFTP browser and remote commands; FTP and FTPS (explicit and implicit TLS, client certificates).
- **Object storage:** Amazon S3 and S3-compatible providers (Backblaze B2, IDrive e2, Wasabi, Cloudflare R2, DigitalOcean Spaces, Google Cloud Storage via HMAC, Oracle, Linode, Scaleway, Hetzner, Storj, MinIO, Alibaba OSS), and Azure Blob Storage with every Storage Explorer sign-in method (account key, connection string, SAS, Entra ID, anonymous, Azurite).
- **Network paths** for TCP connectors: SSH tunnel (with jump hosts), SOCKS5 and HTTP CONNECT proxies.

### Working with data
- SQL editor with highlighting, autocomplete, tabs, run statement / selection / script, cancel, and history.
- **SSMS-style graphical execution plans** (cost per operator, row-count arrows) next to the classic plan tree.
- Virtualized results grid, inline editing with safe batched writes, CSV/JSON/SQL export, import.
- Object explorer (SSMS layout for SQL Server), DDL view, users and privileges, session and lock monitoring, metrics.
- Backup and restore via `pg_dump` / `mysqldump` / `mariadb-dump`, and SQL Server server-side backups.
- Folders and environments (Development / Testing / Staging / Production) with confirmation for destructive actions on production.
- ⌘K / Ctrl+K search across connections, objects and commands; favourite connections pinned on Home.
- Original and Cartoon styles, each in dark and light.
- ER diagrams, schema compare, result charts, snippets and a SQL formatter.

### Security
- Passwords, keys, tokens and passphrases live only in the OS credential store (macOS Keychain, Windows Credential Manager, Linux Secret Service), never in plain files.
- SQL history and connection URIs with embedded passwords are encrypted at rest (AES-256-GCM, key in the credential store).
- SSH host keys are checked against `~/.ssh/known_hosts`; a new key is shown with its SHA-256 fingerprint and trusted only when you confirm it.
- Read-only connections, restore refuses dump files that would run shell commands, passwords are redacted from logs and error reports.
- Full findings and fixes: [docs/SECURITY_AUDIT.md](https://github.com/openvclient/openvclient/blob/main/docs/SECURITY_AUDIT.md).

### Help when things go wrong
- Plain-language explanations under connection errors ("nothing is listening on that port", "the server rejected the credentials"…), **Copy diagnostics**, and a log file you can open from Settings.
- In-app update check against GitHub Releases (can be turned off in Settings).

## Known limitations
- Kafka, Cassandra, Oracle, Db2 and JDBC are not available yet.
- SSH Kerberos/GSSAPI login is not supported, and a jump host can sign in only with an unencrypted key file or ssh-agent.
- PostgreSQL/MySQL `require` TLS modes encrypt but do not verify the server certificate yet.
- Very large file transfers over FTP and Azure are held in memory (SFTP now streams); Azure uploads over 4 GiB and S3 uploads over 5 GiB are refused (no multipart upload yet).
- Windows/integrated SQL Server sign-in and the Windows ARM64 build have not been tested on real hardware.
- FTPS, Kingbase and the cloud S3 provider presets are not yet tested against live servers (the shared S3 code is tested against MinIO and SeaweedFS).
- The full list is in [docs/QA_REPORT.md](https://github.com/openvclient/openvclient/blob/main/docs/QA_REPORT.md).
